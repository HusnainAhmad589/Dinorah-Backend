# Dinorah Jewellery — React + TypeScript Frontend (Sprint 1)

This is the Vite + React + TypeScript frontend application for **Dinorah Jewellery**, providing client registration, login, JWT token persistence, and role-based route protection.

---

## 🎨 Features

- **Luxury Brand Aesthetics**: Custom gold and emerald accents, dark glassmorphism, Cormorant Garamond serif typography, and micro-interactions.
- **Strict TypeScript**: Fully typed forms, responses, user models, and API interfaces.
- **Client & Admin Role Access**: Interactive switching between customer dashboard and privileged admin views.
- **Live API Interactive Tester**: Test `GET /api/auth/me` and `GET /api/auth/admin-only` directly from the UI with real-time response inspection.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```

### 3. Run in Development Mode
```bash
npm run dev
```

### 4. Build and Typecheck
```bash
npm run build
```
